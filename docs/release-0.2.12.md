# Minha Coleção de Jogos 0.2.12

Esta versão atualiza o aplicativo para a baseline Zumbra 0.12.12.

## Correção

- A scrollbar nativa C11 fica visível no gutter reservado da listagem e da barra lateral.
- O espaço à direita deixa de parecer uma margem vazia maior que a margem esquerda.
- O comportamento da versão empacotada fica alinhado ao backend SDL3 Go/cgo usado no desenvolvimento.

## Compatibilidade

- Banco SQLite e migrations inalterados.
- JSON, CSV e preferências inalterados.
- Dados existentes preservados.
