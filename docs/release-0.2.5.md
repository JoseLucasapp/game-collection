# Minha Coleção de Jogos 0.2.5

- Edição de texto completa fornecida pela Zumbra 0.12.5: caret, setas, mouse, seleção, copiar, recortar e colar.
- Scrollbars em gutter dedicado, sem atravessar inputs ou cards.
- Miniatura quadrada da capa no lado esquerdo dos cards.
- Novos campos de valor, descrição, link e nota.
- Modal **Ver mais** com capa, dados completos e ações externas.
- JSON versão 2 e CSV de onze colunas, mantendo importação compatível com a versão 1.
- Migration SQLite 3 para os novos campos.
