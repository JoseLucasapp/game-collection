# Minha Coleção de Jogos 0.2.1

Correção visual final do Z16.

- selects exibem dropdown real;
- diálogos centralizados, sem overflow e com fundo desfocado;
- todos os diálogos possuem botão `X` no cabeçalho;
- estatísticas usam linhas e cards reais, sem sequências `\\n` visíveis;
- capas abrem primeiro em um visualizador interno;
- visualizador de capa possui opção para abrir o arquivo externamente;
- suporte visual a PNG, JPEG e BMP no Linux quando SDL3_image ou GdkPixbuf estiver disponível.
