# Minha Coleção de Jogos 0.2.2

## Interface

- botões com texto corretamente centralizado;
- textos longos limitados ao tamanho do controle;
- botão de fechar no canto superior direito dos modais;
- selects com chevron gráfico;
- barra lateral recolhível e expansível;
- layout expandido preservado ao reabrir a barra lateral.

## Estatísticas

- gráfico de pizza para mídia física e digital;
- gráfico de barras das principais plataformas;
- tabela estruturada com plataforma e quantidade de jogos;
- cards e gráficos mantidos dentro do modal, sem overflow.

## Runtime requerido

Zumbra 0.12.2 ou superior.
