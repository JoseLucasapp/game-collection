# Minha Coleção de Jogos 0.1.0

Primeira versão funcional de referência do Z16.

## Incluído

- catálogo local em SQLite;
- criação, edição e exclusão de jogos;
- busca por nome, plataforma e franquia;
- ordenação por nome, plataforma, franquia e cadastro recente;
- temas claro e escuro;
- atalhos de teclado;
- smoke tests headless na VM e no backend nativo;
- manifesto de distribuição para Linux, Windows e macOS.

## Gate de aceitação

A versão permanece candidata até o fluxo gráfico completo ser validado no Debian: criar um jogo, reiniciar o aplicativo, editar, buscar, alterar a ordenação e excluir.
