# Minha Coleção de Jogos 0.2.11

Esta versão atualiza o aplicativo para a baseline Zumbra 0.12.11.

## Correção

- O executável nativo C11 encerra normalmente sem `double free or corruption (fasttop)`.
- A correção pertence ao runtime gráfico da Zumbra; não houve mudança funcional no aplicativo.

## Compatibilidade

- Banco SQLite e migrations inalterados.
- JSON e CSV inalterados.
- Preferências e dados existentes preservados.
