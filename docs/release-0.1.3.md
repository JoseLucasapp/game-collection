# Minha Coleção de Jogos 0.1.3

## Correções visuais

- Cards reduzidos de 80 para 72 pixels.
- Padding superior reduzido para aproximar o título do topo do card.
- Título e metadados usam alturas explícitas, evitando espaço vertical excedente.
- Passo de rolagem ajustado de 88 para 80 pixels, acompanhando a nova altura do card mais o gap.
- Requisito mínimo atualizado para Zumbra 0.11.3, que remove scrollbars indevidas de labels, botões e containers comuns.
